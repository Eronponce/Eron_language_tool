LanguageTool via Docker

Fluxo atual recomendado:

1. Baixe o LanguageTool com:
   powershell -ExecutionPolicy Bypass -File .\instalar-lt.ps1

2. Remova qualquer atalho antigo do Startup com:
   powershell -ExecutionPolicy Bypass -File .\gerenciar-lt-docker.ps1 remove-startup

3. Suba o container com:
   powershell -ExecutionPolicy Bypass -File .\gerenciar-lt-docker.ps1 up

4. Valide a API com:
   powershell -ExecutionPolicy Bypass -File .\gerenciar-lt-docker.ps1 test

5. Veja status e logs quando precisar:
   powershell -ExecutionPolicy Bypass -File .\gerenciar-lt-docker.ps1 status
   powershell -ExecutionPolicy Bypass -File .\gerenciar-lt-docker.ps1 logs

Endpoint local:

- http://localhost:8081/v2/languages

Arquivos principais:

- Dockerfile
- docker-compose.yml
- gerenciar-lt-docker.ps1

Notas:

- O container sobe em foreground e fica sob supervisao do Docker.
- O compose usa restart unless-stopped, entao o servico volta sozinho quando o Docker estiver ativo.
- Se quiser mais memoria, ajuste LT_JAVA_XMX no docker-compose.yml.
- Os scripts iniciar_languagetool.bat e iniciar_oculto.vbs ficaram como legado e nao sao mais o caminho recomendado.
